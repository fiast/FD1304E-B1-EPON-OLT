## 3. Таблица ONU — общая информация

База: `.1.3.6.1.4.1.17409.2.3.4.1.1.<col>.<ONU_ID>`

| Col | Содержимое | Формат |
|---|---|---|
| 2 | Имя/описание ONU | STRING, напр. `epon 0/1/1 onu 1 lenina205-xleb` |
| 3 | Признак (у всех `1`) | INTEGER |
| 7 | MAC-адрес | Hex-STRING |
| 8 | **Статус: 1 = online, 2 = offline** | INTEGER |
| 10 | LOID | STRING |
| 12 | Дата выпуска | STRING |
| 13 | Версия ПО ONU | STRING |
| 18 | Uptime ONU | Counter32, сек |
| 25 | Вендор | STRING (`HWTC`) |
| 26 | Тип ONU | STRING (`XPON(0x58504f4e)`) |
| 27 | Версия железа | STRING |
| 28 | MAC-адрес (дубль col7) | Hex-STRING |

`ONU_ID` — уникальный идентификатор ONU, напр. `21495809` (epon 0/1/1 onu 1), `21504001` (epon 0/1/3 onu 1).

## 4. Таблица ONU — оптические параметры

База: `.1.3.6.1.4.1.17409.2.3.4.2.1.<col>.<ONU_ID>.1.<port>`

**Внимание:** индекс составной — `ONU_ID.1.<port>`, где `<port>` — порт EPON (совпадает с
последним числом в имени ONU, напр. `epon 0/1/3` → `port=3`). Обращение по одному `ONU_ID`
даёт `No Such Instance`.

| Col | Содержимое | Масштаб |
|---|---|---|
| 4 | Rx Optical Power | × 0.01 dBm (`-2114` → `-21.14 dBm`) |
| 5 | Tx Optical Power | × 0.01 dBm |
| 6 | Напряжение | × 0.001 V (`1215` → `1.215 V`) |
| 7 | Температура | × 0.0001 °C (`332000` → `33.2 °C`) |
| 8 | Ток смещения лазера | × 0.001 mA (`2725` → `2.725 mA`) |

Пример (фрагмент `snmpwalk`):
```
.1.3.6.1.4.1.17409.2.3.4.2.1.4.21495809.1.1 = INTEGER: -2114   # Rx -21.14 dBm
.1.3.6.1.4.1.17409.2.3.4.2.1.5.21495809.1.1 = INTEGER: 186     # Tx 1.86 dBm
.1.3.6.1.4.1.17409.2.3.4.2.1.6.21495809.1.1 = INTEGER: 1225    # 1.225 V
.1.3.6.1.4.1.17409.2.3.4.2.1.7.21495809.1.1 = INTEGER: 332000  # 33.2 C
.1.3.6.1.4.1.17409.2.3.4.2.1.8.21495809.1.1 = INTEGER: 2725    # 2.725 mA
```

## 5. EPON-порты — статистика (`.1.3.6.1.4.1.17409.2.3.3.5`)

База: `.1.3.6.1.4.1.17409.2.3.3.5.1.<col>.1.1.<epon ifIndex>`

| Col | Предполагаемое содержимое |
|---|---|
| 4 | ? (значения вида 327…329 — интерпретация не подтверждена) |
| 5 | ? (значения 1085…2690) |
| 6 | ? (значения 678…820) |
| 7 | Похоже на средний Rx по порту × 0.01 dBm (напр. `-2070`, `0` при отсутствии ONU) |

Эти колонки **не включены** в шаблон, так как их семантика не подтверждена практикой.

